# MicroCalculator
A Calculator That Supports Microcontroller like Arduino,ESP32, Raspberry Pi Pico etc

# Know these about tiers:
Tier 1: Well Updated and I recommend this tier for every day use and supports many calculations and native testing for Windows Mac and Linux
And it Supports FPU meaning more faster cal

Tier 2: Longer Updates and slower Calculations then Tier 1 and I recommend this tier for beginners and slower calculator and it doesn't support FPU

# limitations:
1. Soft-FPU is Slow because of lack of FPU
2. Basic Functions supported not scientific because of poor performance of tier 2 boards
3. History may lost because of RAM when you turn off Microcontroller
# Tier 1 Boards:
1. Expressif :ESP32-P4,ESP32-S3,ESP32(Original)
2. QEMU : MPS2-AN386(Cortex M4),MPS2-AN500(Cortex M7),MPS2-AN505(Cortex M33)
3. STM32 : STM32F4/STM32F7/STM32H7 Series
# Tier 2 Boards:
1. Arduino (AVR) : Uno,Nano,Mega
2. Raspberry Pi : Pico
3. STM32 : STM32F1,STM32F0,STM32G0,STM32L0
4. Generic : ATtiny85 CPU Boards
